# Fuelino

This page summarizes the latest info, datasheets, presentations, and software available for **Fuelino Proto4**. For more information about **Fuelino project**, please visit [this page from the waybackmachine](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/category/electronics/fuelino-project/).
if some links are missing, please check the content of this doc folder.

## Documentation and Resources

- **Installation Manual** (example: Honda CBR125R): [Fuelino_Proto3_installation_manual_20170114](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2017/01/Fuelino_Proto3_installation_manual_20170114.pdf). This guide explains how to install Fuelino Proto3 on a Honda CBR125R. The installation should be done only by experienced people. For Proto4 the installation is the same.

- **Electrical Schematic**: [Fuelino_p4_schematics](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2019/04/Fuelino_p4_schematics.pdf). This PDF file shows the electrical connections of Fuelino Proto 4.

- **Board Layout**: [Fuelino_p4_board](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2019/04/Fuelino_p4_board.pdf). This file shows how the components are located on the board.

- **Eagle Schematic and Gerber data**: [Fuelino_p4_schematics](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2019/04/Fuelino_p4_schematics.pdf). For manufacturing, use this ZIP file: [Fuelino_Proto_P4_Gerber](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2019/04/Fuelino_Proto_P4_Gerber.zip).

## Software

- **Software for Arduino Nano v3**: [fuelino_ducati_v_1_0_beta1_20180815](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2018/08/fuelino_ducati_v_1_0_beta1_20180815.zip). Requires [Arduino IDE](https://web.archive.org/web/20241111162952/https://www.arduino.cc/). Uses modified SDFat library (**SDFatYield**) included in the ZIP.

- **Drivers for Arduino Nano v3** compatible board: [Fuelino Drivers CH340](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2016/10/Fuelino_Drivers.zip). Necessary for Windows to recognize the Fuelino module.

- **Fuelino Calibration Tool** for PC (Windows 10): [Fuelino_calibration_tool_20170311](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2017/01/Fuelino_calibration_tool_20170311.zip). Includes PDF manual.

- **Service commands manual** (for RealTerm): [fuelino_service_commands_v1-1_20161027](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2016/10/Fuelino_service_commands_V1.1_20161027.pdf). Explains the service commands protocol.

- **Log file converter**: [Fuelino_log_file_converter_20170317](https://web.archive.org/web/20241111162952/http://www.monocilindro.com/wp-content/uploads/2017/03/Fuelino_log_file_converter_20170317.zip). Converts binary data to CSV.

## Additional Resources

- **Presentation**: [Fuelino_Proto4_presentation_20190406](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2019/04/Fuelino_Proto4_presentation_20190406.pdf). Explains the pin-out for Fuelino Proto4.

- **BOM** (Bill of Material): [fuelino_proto3_bom](https://web.archive.org/web/20241111162952/https://www.monocilindro.com/wp-content/uploads/2016/12/Fuelino_Proto3_BOM.xlsx). List of components needed to build Fuelino.
